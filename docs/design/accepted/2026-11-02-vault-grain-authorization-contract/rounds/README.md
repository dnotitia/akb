# Rounds

This record closes [#407](https://github.com/dnotitia/akb/issues/407). The
issue's first question was settled in the public rounds that
[Source-Keyed Grant Contributions](../../2026-08-26-source-keyed-grant-contributions/rounds/README.md)
records. This record adds two rounds:

- **Subject round, 2026-08-27.** The
  [last comment on #407](https://github.com/dnotitia/akb/issues/407#issuecomment-5435843810)
  measured the first rule-driven consumer against a real deployment. It found
  that the measurement did not decide the subject question. It then decided the
  question on other grounds: a contribution's subject is a user, and AKB Core
  has no native group subject. The comment also named what to watch instead,
  which this record uses as the reopen trigger for set subjects (§7).
- **Direction round, 2026-11-02.** The repository owner, who opened #407,
  chose a direction for the remaining questions. The Vault stays the only
  resource that carries policy. Collection, Document and Table-row grains are
  deferred, each with a reopen trigger. The current contract is documented
  as it is.

No implementation round followed, because the decision changes no code.
